# Vibecode 审计与治理说明

## 目标

Vibecode 模块用于识别与治理“看起来像由生成式工具、模板脚手架或自动化流程生成的代码/文档”这类风险信号。它并不试图替代人工判断，而是提供可审计、可配置、可阻断的前置线索。

## 核心能力

- 关键词识别：识别 `vibecode`、`vibe`、`prompt-driven` 等线索
- 来源分类：区分 `llm_generated`、`template_generated`、`handwritten`、`unknown`
- 证据收集：记录触发的关键词与模式
- 风险评分：根据关键词密度和来源线索生成 severity 与 risk level
- 治理策略：通过配置文件定义 `block_on` 和 action 列表

## 输出产物

运行以下命令后，可生成：

```bash
python -m specomega vibecode "Generated by ChatGPT: def hello(): return 'hi'" --output-dir .specomega/reports
```

产物包括：

- `vibecode_report.json`：结构化结果，适合程序化消费
- `vibecode_report.md`：适合人工 Review 的摘要
- `vibecode_report.html`：适合浏览器打开的审计视图
- `vibecode_report.csv`：适合导入表格工具做汇总
- `vibecode_gate.txt`：适合作为审批或治理门禁的简洁结论

## 配置项

配置文件位于 [.specomega/vibecode_config.json](../.specomega/vibecode_config.json)，支持：

- `threshold`：判定是否为 Vibecode 的最小分数
- `rules`：为不同来源类型指定风险等级和建议动作
- `policy.block_on`：定义在什么风险级别下应当阻断

示例：

```json
{
  "threshold": 1,
  "policy": {"block_on": "medium"},
  "rules": {
    "llm_generated": {"risk": "high", "actions": ["review"]},
    "template_generated": {"risk": "medium", "actions": ["inspect"]}
  }
}
```

## 使用建议

- 对关键路径代码库建议使用更严格的 `block_on` 配置
- 对文档或示例目录则可使用较宽松策略
- 将 `vibecode_gate.txt` 与 CI 或审批流程串联，形成前置治理节点
